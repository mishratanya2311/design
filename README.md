Welcome to **CodeCanvas**, a creative collection of visual designs, animations, and digital experiments built using code.

## 🌻 Design #01 — Sunflowers: Drawn into Bloom

My first creation in this collection is an animated sunflower artwork built with **HTML, CSS, JavaScript, and SVG**.

The animation gradually brings a cluster of sunflowers to life against a dark background, revealing golden petals, detailed flower centers, and green stems and leaves through a drawing-and-painting effect.

### ✨ Features

- 🌻 **Animated sunflower artwork** — A cluster of five sunflowers brought to life with code.
- 🎨 **Golden gradients** — Layered yellow and orange petals for a rich, warm appearance.
- 🌿 **Natural details** — Green stems, leaves, petal veins, and textured flower centers.
- 🌌 **Dark aesthetic** — A near-black background with a subtle golden glow.
- ✍️ **Draw-on animation** — SVG paths animate as if the artwork is being drawn in real time.
- 📱 **Responsive layout** — Designed to fit different screen sizes.

### 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling, gradients, transitions, and drawing animations
- **JavaScript** — Dynamic SVG generation and animation sequencing
- **SVG** — Scalable flower shapes, paths, and visual effects

### 🚀 Run Locally

No frameworks, external libraries, or package installations are required.

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `sun.html` in your browser.

4. Watch the sunflowers bloom! 🌻

You can also open the HTML file directly in your browser without cloning the repository.
